# ft_transcendence
프로젝트 기간 : 2023/03/06 ~ 2023/05/20
웹 기반 온라인 탁구 게임 프로젝트입니다.

### 내가 기여한 부분

게임 페이지 제작

- 유저 프로필 UI 구현
    - DB와 연결해서 유저 프로필 불러오는 기능
- 소켓의 status 옵션을 활용해 페이지 비정상 접근 차단
    - 플레이어의 소켓 보유 여부를 판별
- 플레이어가 비정상 플레이를 했을 때 예외 처리
- 탁구 게임 새로운 모드 추가

### 사용 기술

- React / TypeScript
    - 게임 페이지 제작 및 로직 구현에 사용했습니다.
- Docker
    - 프론트 / 서버 / DB를 각각 컨테이너로 분리해서 제작했습니다.
